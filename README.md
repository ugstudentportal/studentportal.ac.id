# UG StudentSite — Replika Tampilan

Project sederhana HTML + CSS + JavaScript yang dibuat berdasarkan screenshot referensi.

## Struktur
- `index.html` — struktur halaman
- `style.css` — seluruh styling/layout
- `script.js` — carousel pengumuman dan interaksi tombol

## Menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder `ug-studentsite` di Visual Studio Code.
3. Buka `index.html`.
4. Klik kanan → **Open with Live Server** jika extension Live Server sudah terpasang.
   Atau buka `index.html` langsung di browser.

Tidak membutuhkan framework atau instalasi npm.
